##  Overview

This repository contains a collection of data analysis projects built using Microsoft Excel. Each project demonstrates data cleaning, data transformation, and data visualization techniques using real-world datasets obtained from various sources such as online platforms and tutorial videos.

The goal of this repository is to showcase practical data analysis skills and the ability to turn raw data into meaningful insights using Excel.

---

## Objectives

* Perform data cleaning and preparation
* Analyze datasets using Excel formulas and Pivot Tables
* Create interactive dashboards
* Generate insights from data

---

##  Tools & Skills

* Microsoft Excel
* Data Cleaning
* Pivot Tables
* Data Visualization
* Basic Data Analysis
